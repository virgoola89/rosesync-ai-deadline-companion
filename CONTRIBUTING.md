# Contributing to RoseSync

RoseSync is currently a competition prototype.

## Local setup

```bash
npm install
npm run dev
```

## Before committing

```bash
npm test
```

## Product guardrails

- Keep user agency explicit.
- AI suggestions should be optional and editable.
- Avoid guilt-based or punitive progress language.
- Do not represent a slow day as failure or a dying plant.
- Keep daily planning lightweight.
- Preserve the rose metaphor across product surfaces.
