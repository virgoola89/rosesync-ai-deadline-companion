GOOD TO KNOW

What this prototype really does.

Does this website change my phone's real lock screen?

No. It previews the design in a simulated phone. A native Android build is needed to apply and refresh a device wallpaper automatically.

Does Bloom Boost call Gemini here?

Not in this static showcase. The sample messages are rule-based. The connected app can use Gemini through a secure backend, with user approval before adding suggested tasks.

Is the weather in the preview live?

No. The four buttons are demo modes. A connected version can use a weather service after the user gives location permission.

Will my demo choices be saved?

Yes, in this browser using localStorage. There is no account or shared database in this showcase. Clearing browser storage resets the demo.
